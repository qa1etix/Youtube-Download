# Скрипт загрузки видео с Youtube
Скрипт делит видео на Mp4 + mp3 составляющие, загрузка в качестве на выбор из доступных
---
# Запуск
`python install -r requirements.txt` - установка зависимостей
Вам нужно загрузить файлы куки из своего браузера, сбросив в корневую папку с main.py
Проверьте, что имя файла куки "cookie.txt"
Для запуска используйте *start.bat*, если используете venv, то *start_venv.bat*
Полученные файлы смотреть в ./output
---
