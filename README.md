# 🎬 YouTube Video & Audio Splitter (EJS 2026 Edition)

Автономный скрипт на Python для скачивания видео с YouTube в выбранном качестве и его мгновенного разделения на видеопоток (без звука) и чистую аудиодорожку (.mp3) без перекодирования.

## ✨ Особенности проекта
- **Обход SABR-защиты (2026):** Интеграция с облачным EJS-дешифратором и использование системного Node.js для прохождения `n challenge`.
- **Без потери качества:** Видеопоток извлекается методом прямого копирования (`vcodec="copy"`), что экономит ресурсы процессора.
- **Умное именование:** Финальные файлы автоматически переименовываются по маске `Название_Видео [Качество]` с очисткой от запрещенных символов Windows.
- **Поддержка Cookies:** Возможность использования локального файла сессий для скачивания приватных видео.

---

## 📂 Структура проекта

Для корректной работы файлы в вашей папке должны располагаться следующим образом:
```text
YoutubeDownload/
├── .venv/            # Виртуальное окружение Python, используйте по желанию
├── output/           # Папка, куда сохраняются готовые файлы
├── cookies.txt       # Текстовый файл с куками из браузера (Обязательно)
├── ffmpeg.exe        # Обработка медиа
├── main.py           # Основной код скрипта на Python
├── requirements.txt  # Зависимости Python
├── start.bat         # Запуск из глобальной среды Python
└── start_venv.bat    # Запуск python из .venv
```

---

## 🛠️ Системные требования
1. **Python 3.10 или новее**
2. **Node.js** (установлен глобально в системе через `winget install OpenJS.NodeJS` или с официального сайта для решения JS-задач YouTube).
3. **FFmpeg** (файлы `ffmpeg.exe` должнен быть вручную скопированы в корень папки проекта).

## 📥 Инструкция по установке и запуску

Выполните эти шаги последовательно в терминале вашей папки проекта:

1. **Создайте чистое виртуальное окружение (опционально):**
   ```bash
   python -m venv .venv
   ```

2. **Обновите менеджер пакетов и установите зависимости:**
   ```bash
   .venv\Scripts\python.exe -m pip install --upgrade pip
   .venv\Scripts\python.exe -m pip install ffmpeg-python js2py
   .venv\Scripts\python.exe -m pip install -U --pre "yt-dlp[default]"
   ```

3. **Запустите проект:**
   Просто дважды кликните по файлу `start.bat` или `start_venv.bat` в проводнике Windows. Вставьте ссылку на видео и выберите желаемое качество из предложенного списка.
