# Скрипт загрузки видео с Youtube
> Скрипт делит видео на Mp4 + mp3 составляющие, загрузка в качестве на выбор из доступных

---

# Запуск
1. Скачайте репозиторий используя git clone *ссылка на этот репозиторий*

2. `python install -r requirements.txt` - установка зависимостей

3. Вам нужно загрузить файлы куки из своего браузера, сбросив в корневую папку с main.py

Проверьте, что имя файла куки "cookie.txt"

4. Для запуска используйте *start.bat*, если используете venv, то *start_venv.bat*

5. Ввод ссылки, выбор качества загружаемого видео

6. Полученные файлы смотреть в ./output

---
